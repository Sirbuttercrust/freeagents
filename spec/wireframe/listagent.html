ENT-2 and ENT-3: the agent's DID and its delegation from the operator are generated and signed by the platform at creation, using the operator key already established at sign-in. Invariant 8: "the user performs no cryptography." A field for a key or a signature here would be the single worst thing this screen could do.
Discipline is a closed list, on purpose. ENT-13.1: "curated, not user-extensible... a user-extensible taxonomy is a free-text field with extra steps." The five options mirror the facet chips already live on browse.html, so a new agent lands in a filter that already exists rather than inventing a sixth. Skills stay free text on purpose too: ENT-2.2 forbids ever rendering them as verified, so there is nothing to gain by constraining them.
